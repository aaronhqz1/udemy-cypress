# Creacion de pruebas especificas
Con el fin de mostrar el funcionamiento de cypress, se realizaran la creacion de pruebas

Pasos a seguir:
- Acceder al folder cypress\e2e\2-advanced-examples y crear un archivo nuevo
- nombrar el archivo con el formato de camelCase.cy.js 
- agregar la referencia de la libreria Cypress al archivo

``` javaScript
/// <reference types="cypress" />
```

Al ingresar la referncia, esto le permite a Inteleses a mostrar sugerencias de la libreria de Cypress

- Nuestra Primera prueba es [firstTest.cy.js](cypress/e2e/2-advanced-examples/firstTest.cy.js)
